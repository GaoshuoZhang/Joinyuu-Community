# 企业代办后续工作与运营启用条件

本文件记录当前收集与办理闭环之外的工作，关联 [企业代办规范](enterprise-agency.md)。以下项目未实现或尚未获准启用，不因代码中已有入口而自动生效。

## 下一阶段收费

社区可选择免费或收费。应分别设计服务申请、报价确认、支付订单与办理状态；金额由服务端报价快照确定，明确收费主体、支付回调幂等、退款/撤回关系、对账和凭证。复用现有支付基础能力前核对适用业务及权限，不在表单payload内塞付款状态，不在当前六态中混入“已支付”。当前以线下沟通费用为边界，不能展示未经配置的“免费”或“已付款”。

## 需要运营确认后启用

- 新服务开关默认关闭，按社区实际能力逐项开启；工作人员核实代表授权、地区可办范围与涉及的承接资格。
- 孤儿附件自动删除默认关闭。当前代码默认72小时宽限（允许24–720）；计划建议7天，但尚未成为已确认决策。先确定上传页告知与保留期限，观察预检日志后再开启，已绑定历史材料不参加此任务。
- 为各地区/事项维护可核验的办事指南、核对日期与条件卡版本，支持事项变更后的告知；当前由工作人员人工评估，不承诺全国统一条件或办结时限。
- 为未提交、被替换和终态材料明确保留、归档、删除申请及备份处理；当前未实现自动清除历史申请材料。

## 明确暂缓

- 跨端“待补充”角标及me聚合提醒。
- 电子合同、办理结果附件回传、自动化对账及收费订单体系。
- 工商变更税务前置凭证等依地区决定的强校验。
- 独立时间线事件ID/可显式提交的修订版本协议；当前使用事务行锁及状态冲突校验保护记录，申请/重提另有请求幂等键，不把分钟时间戳当作并发版本。
