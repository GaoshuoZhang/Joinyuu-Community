# 移动客户端 UI/UX 整改记录（2026-10-15）

本次依据原审查 20 项及四账号补查新增 4 项，落实代码修复与规则澄清。继续使用 TDesign Mobile Vue 1.16.2 及现有样式 Token。编号保持原报告顺序，新增项为 21–24；表格按优先级排列。

## 处理结果

| 编号 | 优先级 | 问题 | 本次处理 |
|---|---|---|---|
| 1 | P1 | 成立时间回显错误、默认十年下限 | 使用 `v-model:value`，成立月份显式从 1800-01 起选，上限为当前月份；预约、申请和需求交付日期选择器同步修正绑定。 |
| 2 | P1 | 共享分页追加不触发响应式更新 | 以新数组替换 `shallowRef` 内容；总数不变时最后一页也更新列表及 `hasMore`。 |
| 3 | P1 | 活动取消规则跨入口不一致 | 两个客户端入口共用 `canCancelEnrollment`；已通过报名按配置时限、改期时间判断，等于截止即不可取消；待审及候补不套用已通过报名的时限。已签到、活动取消或结束时，客户端与服务端均阻止取消。详情接口补齐配置时限。 |
| 21 | P1 | 企业成员列表可见项目、详情拒绝访问 | 关联企业成员可读取企业需求方项目及所属附件；来源需求的历史企业主体也纳入列表。接口分别下发 `canSubmit`、`canAccept`，成员查看权限不会自动获得验收权限，服务端继续独立鉴权。展示需求方快照名称，避免将查看者误写为发起人。 |
| 4 | P2 | 企业规模已有值不能回显 | 对齐后台现用的四档规模，使用 TDesign `RadioGroup`。历史其他分段作为额外选项保留，不擅自换算人数区间；提交校验所选值是否存在于选项中。 |
| 5 | P2 | 加载、错误组件缺少导入 | 为投稿页补齐 `ListSkeleton`、`EmptyBlock`，为介绍页补齐 `EmptyBlock`。 |
| 6 | P2 | 投稿栏目失败无说明及重试 | 栏目区域区分加载、请求错误、暂无栏目；错误分支提供重试入口。 |
| 7 | P2 | 历史需求日期被误读为响应截止 | 核对当前类型及发布表单后，确认旧 `deadline` 已不再收集，新需求使用 `deliverBy`。共享日期文案将旧值明确标为“参考日期……（历史记录）”，不新增与当前业务不符的过期禁响应规则。 |
| 8 | P2 | 搜索清空后刷新恢复旧词 | 清空输入同步移除 URL 的 `q`，清理旧结果、更多入口和请求状态。 |
| 9 | P2 | 部分搜索结果截断后无后续入口 | 需求和活动各取首批 10 条；总数超过已加载数量时展示携带关键词的“查看更多”入口，进入对应分页列表。 |
| 10 | P2 | 项目交付与退回草稿无提示丢失 | 按里程碑保存独立的说明、附件及退回原因；切换与关闭编辑区保留草稿，成功提交后清除对应草稿。复用离页保护，覆盖隐藏草稿。 |
| 11 | P2 | 交付证据只能看裁剪缩略图 | 缩略图由具名 TDesign `Button` 触发 `ImageViewer`，支持完整图片、图片序号及文件名。 |
| 12 | P2 | 返回箭头缺少按钮语义且触控区窄 | 应用壳 `Navbar` 左插槽直接使用具名 TDesign `Button`，44×44px，直接绑定原返回逻辑。 |
| 13 | P2 | Tabs 面板名称与当前标签不一致 | 五处 Tabs 显式标注业务 value；ARIA 关系按 value 匹配存活面板。面板销毁、恢复及选中变化都同步关系，不再按存活面板的 DOM 下标配对。 |
| 14 | P2 | 密码显隐不可通过键盘操作 | 新增共享 `PasswordInput`，登录、注册、找回密码和安全页统一使用。具名 44×44px 按钮提供显隐状态；原生输入保留密码管理器需要的 autocomplete token。 |
| 15 | P2 | 异步启用的点击行缺少键盘语义 | `v-pressable` 补齐动态更新、停用和卸载清理；恢复原有属性；不重复增强原生控件，也不拦截子控件的键盘事件。 |
| 16 | P2 | placeholder 覆盖可见字段名称 | 先关联可见 label，再为没有名称的输入提供 placeholder 兜底；后出现的 label 会清理自动生成的占位名称。 |
| 22 | P2 | 无操作权限的会话企业身份混入表单 | 共享 `authorizedActionIdentities` 合并、去重，并按权限接口确认的企业集合过滤全部会话企业。应用于投稿、发布需求、响应和空间预约；接口失败时不以会话快照补回企业身份。共享身份选择器改为 `RadioGroup`。 |
| 23 | P2 | 普通成员能打开退驻提交确认 | 退驻按钮、确认处理函数、实际请求函数都要求负责人身份；成员仍可查看已有申请状态。 |
| 24 | P2 | 新手任务折叠后隐藏链接仍可聚焦 | 设置 `CollapsePanel.destroyOnCollapse`，折叠时销毁任务内容；展开按钮继续提供展开状态。 |
| 17 | P3 | 无企业记录仍提示查看名片 | 无入口的合作企业身份改为“暂未关联企业名片”，不提供无效操作文案。 |
| 18 | P3 | 操作及互斥选择未统一使用 TDesign | 设置、权益重试、头像上传、主题预览、首页任务及横幅触发器采用 TDesign `Button`；企业合作方式、规模及业务身份采用 `RadioGroup`。合作说明完整展示，取消默认描述截断。 |
| 19 | P3 | 个人与公开文章使用不同正文排版 | 我的投稿详情复用公开文章的 `ArticleContent`；两处共用净化、段落与图片排版，正文图片支持 `ImageViewer` 预览。 |
| 20 | P3 | 注释与入口文案漂移 | 修正响应表单收起仍保留内容的注释、社区成员视角注释；积分规则入口统一为“我的留言”。 |

- 新增回归覆盖分页结束、取消时限精确边界及改期、项目读取与操作权限、无关用户和附件鉴权、身份过滤、动态键盘能力、Tabs 懒加载关系、里程碑草稿、密码显隐及搜索 URL/更多入口。
- 实际浏览器使用现有 10001 负责人会话验证：成立月份首次打开及重开显示 2024 年 6 月；10-50人选中；可见字段名优先；返回按钮；人才库/企业库面板名称；搜索清除并刷新；安全页异步操作行及空密码框的空格键显隐。未填写新凭据、提交业务表单或保存权限。
