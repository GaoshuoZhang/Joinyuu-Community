# 聚屿社区 — 整体项目开发规划与进度核对表（Full Spec Check）

> 本文档展示整体项目的里程碑规划与模块进度，是跨会话/跨 agent 的进度唯一事实来源。
> 每完成一个模块，同步更新本文档勾选状态，并按约定在 `docs/` 沉淀对应文档。
> 最后更新：2026-09-08（M0 后台原型全部完成；M0-D 运营设施域落地，积分商城拆分为"积分管理"一级菜单）

## 0. 项目定位

**聚屿社区 Joinyuu Community — 创业社区数字化运营平台**：管理后台（运营方）+ 客户端 Web（居民/企业成员）+ 微信小程序（居民轻入口）三端一体的社区运营系统。

核心业务域：
- **社区成员**：用户与多身份体系（个人用户/社区个人/社区企业/外部企业）、入驻与身份绑定审批、经验值与积分账本
- **业务运营**：需求广场（提交→审核→发布→立项全流程）、项目协作（多承接方占比、里程碑）、活动运营（发布/定时发布、报名审核、签到）
- **运营设施**：资讯内容（原二期规划，已于 M0-D 提前落地原型）
- **积分管理**：商品管理、订单管理、积分规则、积分账单（2026-09-08 由"积分商城"拆分为独立一级菜单）
- **空间管理**：办公位管理、办公室管理、租赁管理、公共空间管理、公共空间预约（2026-09-08 由"办公位管理/公共空间"拆分为独立一级菜单）

开发策略（用户指定）：**以管理后台 Web 作为初始驱动**——先在后台原型中确定实体字段、状态流、API 接口形状与客户端功能边界，再据此实现后端服务与客户端。
