## 0. 项目定位

**聚屿社区 Joinyuu Community — 创业社区数字化运营平台**：管理后台（运营方）+ 客户端 Web（居民/企业成员）+ 微信小程序（居民轻入口）三端一体的社区运营系统。

核心业务域：
- **社区成员**：用户与多身份体系（个人用户/社区个人/社区企业/外部企业）、入驻与身份绑定审批、经验值与积分账本
- **业务运营**：需求广场（提交→审核→发布→立项全流程）、项目协作（多承接方占比、里程碑）、活动运营（发布/定时发布、报名审核、签到）
- **运营设施**（二期）：积分商城、办公位管理、公共空间预约、资讯内容

开发策略（用户指定）：**以管理后台 Web 作为初始驱动**——先在后台原型中确定实体字段、状态流、API 接口形状与客户端功能边界，再据此实现后端服务与客户端。
