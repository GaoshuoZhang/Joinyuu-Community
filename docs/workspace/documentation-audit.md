## 持续维护与核验边界

node scripts/check-docs.mjs 检查 Markdown 本地文件链接，已接入根仓 CI。node scripts/generate-reference.mjs --check 检测生成路由和字段与源码是否一致，需要安装 API 依赖。链接检查不替代正文语义审查，也不验证外部网站或生产部署。

本次是按当前本地代码整理的文档审查，不是所有业务分支的重新验收。真实微信登录/支付、供应商权限、生产配置及外部签发工具未重新验证；文档未将其标为验收完成。历史 releases 清单保留当时的路径和状态，查阅时应结合其中记录的 commit。

清理只针对已确认的重复文档和测试临时文件。现有服务使用的 dist、环境配置、私钥、上传数据、数据库卷、node_modules 与小程序构建依赖保留。

缓存清理：自动删除旧 integration-uploads 文件曾被审批策略阻止；用户随后手动清理。2026-10-29 提交前重新检查，该路径下已无文件。该缓存原本被 Git 忽略，其删除不产生仓库提交。

验证结果：32 份 Markdown 的本地文件链接通过；461 个路由和 82 个模型/枚举与生成源一致；根仓 2 项测试通过；小程序静态检查通过（130 JS、92 JSON、76 页），路由重新生成后 app.json 无内容差异，页面链接 dry-run 无需修改。此次未重跑业务数据库 e2e、生产构建或真机验证。
