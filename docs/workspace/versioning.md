# 版本与发布

每个业务仓的 package.json 是该软件版本的唯一来源；四端不再锁步改号。对应更新日志集中在 [版本记录目录](../README.md)。Unreleased 记录未正式发布的改动，正式发布时按实际影响归档版本和日期。

跨仓功能先提交、推送涉及的业务仓，再在根目录执行 `pnpm release:record <发布标识>`。生成的根目录 releases/*.json 记录各仓版本、远程与固定 commit，要求子仓工作树干净且不覆盖同名清单。补充验证、数据库迁移、部署顺序与回滚要求后提交根仓。该命令不会创建 tag、推送、部署或证明生产验收完成。

历史清单中的 remote、commit 和 status 表示记录当时的状态，不回写成当前值；当前远程看 repositories.json 和实际 Git 配置。历史小程序拆仓清单早于 Git 重置，不能用其旧提交替代重置后的初始基线。

接口变更由 API 仓维护并同步中央文档；新增字段优先向后兼容。删除字段、改变状态含义或数据库不可逆迁移需分阶段上线，兼容已发布的小程序客户端。更新日志保留历史事实，不把旧版本的“未实现”描述当作当前能力。
