## 关联记录

### 选项卡组件统一专项（2026-10-30）

- 定位到社区页签高于其他页签的根因：社区、需求、广场、我的需求、我的项目、交易订单各自手写了不同高度（68/72/88rpx）和间距；移动 Web 虽统一使用 TDesign Tabs，但各页仍重复覆写变量。
- 小程序六个页面统一迁移到 TDesign `t-tabs` / `t-tab-panel`，通过 MCP 的 miniprogram 文档确认 `value`、`label`、`change`、`split`、`swipeable` 和 Tabs CSS 变量；统一高度 44px、14px 文本、18px 指示线、3px 指示线厚度，并保留业务页面自己的切换与加载逻辑。
- 移动 Web 的 Community、Projects、Plaza、MyDemands、MyOrders、MyProjects、MyTransactions、TradeOrders 统一 44px Tab 高度、字体、指示线和无分割线配置，删除页面级重复变量。
- 小程序构建排除清单补回 Tabs 的间接依赖（sticky、badge、mixins 等），并在项目检查中增加 TDesign npm 依赖闭包检查，避免组件升级后再次出现“页面空白但模板语法通过”。
- 社区筛选标签补齐与其他筛选区一致的 `td-filter-tag` 外部类；六个切换处理函数均新增回归测试，验证 TDesign `change` 事件、重复选中不重载和业务副作用保持不变。

视觉验证：微信开发者工具重启后社区页实际画面显示 44px 选项卡；“社区服务 / 人才库 / 企业库”三项等高、文字基线一致、指示线位置统一。需求和广场截图亦显示同一高度。曾因开发者工具热重启导致一次无法截图，重启项目窗口后恢复；最终页面截图成功。小程序 npm test 16/16、lint；移动 Web typecheck、lint、154 项测试与 build 通过。

### 按钮与卡片位置专项（2026-10-30）

代码范围为全部 75 个注册页面及公共组件：扫描 80 份 WXML，核对 220 处 `t-button` 和 279 处包含 `card` 类的声明（源码数量，并非同时显示的控件数量），同时检查原生可点元素、卡片容器、横向操作组、固定栏和弹层。TDesign MCP 分别查询 miniprogram / mobile-vue 的 Button、Cell、Grid、Popup、Empty API 与 DOM，并补查 Mobile Fab；ui-ux-pro-max 核对触控间距、安全区与固定元素避让规则。
