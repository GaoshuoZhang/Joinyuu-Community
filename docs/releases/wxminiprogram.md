# 更新日志 · 微信小程序

## [Unreleased]

### 说明

- 本期企业代办（企业注册）仅在移动 Web、管理后台与后端提供，按用户明确要求不移植小程序；小程序端零改动，属于移动 Web/小程序双向同步规则的显式例外。恢复移植时按小程序契约重新实现，不能照搬 Vue 组件与私有附件上传链路。

### 变更

- 交互与展示组件改用 TDesign 作为组件底座（与移动 Web 同族）：`--td-*` 变量桥接客户主题与手动明暗，`state-tag` 改由 `t-tag` 渲染、`empty-block` 改由 `t-empty` + `t-button` 渲染，页面调用方式不变；移除已无实际用途的 `section-header` 组件。
- 广场、社区与全局搜索的搜索框改用 `t-search`（含搜索页的「搜索」动作），删除三处手写搜索框样式与清空按钮。
- 全站表单输入框与多行文本域改用 `t-input` / `t-textarea`（容器与内部输入框分别用 `t-class`、`t-class-input` 控制样式）。
- 「我的」「账号与安全」「通知设置」「关于」「我的记录」「身份指引」与搜索结果的列表单元改用 `t-cell`，右侧自定义内容用 `note` 插槽。
- 全站静态标签与筛选胶囊改用 `t-tag` / `t-check-tag`；类别色位通过 `t-class` 保留。

### 优化

- 打开底部弹层时隐藏自定义底栏，修复弹层底部按钮被底栏遮挡、点不到的问题。
- 底部弹层补进场动效（200ms 滑入 + 遮罩淡入），减弱动效下自动关闭。
- 40 处原本无按压反馈的可点元素（表单选项、上传项、协议行、文字链、弹层关闭等）统一补 `hover-class="press"`，步进器在禁用态不再缩放。
- 可滚动弹层加 `overscroll-behavior: contain`，滚到底不再带动背后页面。
- 阴影收敛为 `@shadow-float` / `@shadow-bar` 两个 token；明暗切换时冻结过渡，消除整页拖影。
- 声明 `tslib` 依赖并重新构建 npm：TDesign 部分组件（如 toast）编译产物依赖它，缺失会导致组件加载失败。
- 全站按钮改用 `t-button`：整宽与内容宽度由行内 `style` 控制（`block` 属性在当前版本实测无效），描边与危险浅底通过 `t-class` 外部类补齐；删除 `.btn` 系列样式与其页面级选择器。
- 组件声明改为按页面按需引入，不写进 `app.json` 全局注册，避免未引用的库代码打进主包。

### 新增

- 全局搜索补充「社区服务」与「空间」两类结果，与移动 Web 的七类对齐：政策直接打开对应条目，空间进入预约页（未登录先登录再回跳）。

### 修复

- 「我的订单」与「现金交易」合并为统一入口「交易订单」：聚合页顶层「现金交易 / 兑换订单」两页签（各自保留原筛选与分页），支持 `?tab=cash|orders` 指定页签；「我的」页宫格合并为一项，角标 = 待付款 + 退款处理中；旧页面移除，全站跳转与文案统一改为「交易订单」。
- 退出账号或登录失效时立即清除底栏未读标记，忽略旧账号延迟返回的未读数。
- 修复“我的”页点击“登录或注册”后误跳编辑资料的问题：登录成功返回“我的”页，已登录时点击头像区域仍进入编辑资料。
- 深色模式消除亮色残留：骨架屏、头像首字兜底、语义色标签（成功/警告/危险）与社区类别色位统一改为明暗双套变量；`app.json` 的 window 配置改为引用 `theme.json`，下拉露底不再固定浅色。
- 修正底栏未读角标引用未定义 `--danger` 变量的问题。
- 「我的」页五项服务宫格排成一行五列，消除末项落单；商城两列商品卡标题固定占两行高度，价格与描述恢复横向对齐。
- 表单选项胶囊补齐按压反馈并提升到 44px 触控高度；筛选 chip 统一为 32px。

### 变更

- 等级标签接入客户主题的等级配色（`utils/level.js`），主题未下发 `levelColors` 时回退品牌标签色。
- 加载态与空态组件补充状态语义和按钮标签，读屏可识别三态切换。
- 客户端以移动 Web 为基线的双向同步规则写入根仓与本仓 AGENTS.md。
- 微信一键登录的身份绑定页在手机号、邮箱后新增账号密码选项，支持用户名/手机号/邮箱及密码验证已有账号，包含错误重试和图形验证码处理。
- 账号与安全新增微信绑定状态和更换入口，通过当前账号验证后关联当前微信；失败保留原绑定且不创建新用户。
- 配置为聚屿社区独立客户端仓库；Git 历史从当前项目代码开始，保留适用的第三方许可证。
- 补齐独立依赖、结构检查和 Agent 规则；图标工具不再读取父目录依赖。
