## [1.5.1] - 2026-10-26

### 本次更新

- 登录页新增注册渠道关闭提示；活动报名支持绑定引导和选填留言，详情展示主讲嘉宾、主办方及标签。

### 新增

- 新增零依赖静态服务脚本 [server.mjs](https://github.com/GaoshuoZhang/Joinyuu-client-mobile/blob/main/server.mjs) 与 `serve` 脚本：供 1Panel「运行环境 → Node.js」容器直接托管移动端产物，其中**实现了 history 路由兜底**（任意未命中路径回落 `index.html`，等价 Nginx 的 `try_files $uri $uri/ /index.html;`），并包含正确 MIME、`index.html` 不缓存、带哈希资源长缓存、路径穿越防护。根脚本新增 `serve:mobile` 与 `start:mobile`（容器内构建后再服务）。
- 内置 `/api` 反向代理：默认转发到容器网络内的 `http://joinyuu-api:7757`（`API_PROXY_TARGET` 可改目标、设为空则关闭），并透传客户端真实 IP——这样「IP + 端口直连前端容器」时接口也能正常调用；已由 Nginx 反代 `/api` 的部署不受影响。
- **「登录 / 注册」统一入口**：登录页（`/login`）改为两屏——第一屏只输入手机号/邮箱/用户名 + 「下一步」；第二屏按标识形态给出登录方式：手机号/邮箱默认**密码登录**（省短信/邮件开销，「忘记密码？」移到密码标签行右侧），密码框下方给「使用验证码登录」，验证码屏（协议勾选 + 60s 倒计时）可切回密码登录。**验证码校验通过后由服务端判定「登录」还是「建号」**（自动建号时提示「注册成功，欢迎加入聚屿社区」）；用户名路径只能用密码登录。页面标题、h1 与标签页标题统一为「登录或注册」。
- 新增协议勾选组件 [src/components/auth/AgreementConsent.vue](https://github.com/GaoshuoZhang/Joinyuu-client-mobile/blob/main/src/components/auth/AgreementConsent.vue)（勾选行 + 协议弹层），登录页验证码屏与注册页共用；验证码屏明示「验证成功后将为你创建新账号（若尚未注册）」。
- **浏览器标签页图标取「系统配置 → 站点信息」的站点 logo**：`GET /api/app/config` 新增下发 `siteLogo`，客户端启动时由 [src/utils/siteBranding.ts](https://github.com/GaoshuoZhang/Joinyuu-client-mobile/blob/main/src/utils/siteBranding.ts) 接管**唯一那个** `link[rel=icon]`（空则回退内置 `/favicon.svg`）。客户主题包的 brand logo 仍用于页面内品牌位，不参与标签页图标。

### 变更

- **注册页（`/register`）降级为兜底页**：仅保留「用户名 + 密码 + 确认密码 + 协议勾选」，移除邮箱/手机号渠道与验证码；短信或邮箱通道可用时注册统一由登录页的验证码流程自动建号，本页只在**两种通道都不可用**时从登录页给出入口（页面直连仍可访问）。页内明示「用户名注册不支持验证码登录，也无法自助找回密码」。
- **账号与安全页（`/me/security`）按「是否已设置密码」分两态**：`hasPassword=false`（验证码登录自动建号，服务端下发的账号为「未设置密码」）时入口显示「设置登录密码」，弹窗隐藏原密码字段、免验证码，保存后与改密一致强制重新登录；已设置密码的账号维持「修改登录密码」（须原密码）。
- 登录页通道降级：短信或邮箱单缺时隐藏对应验证码入口并提示改用另一渠道；两者都不可用时提示改用密码登录，并把「用户名注册」作为兜底入口（`registrationOpen=false` 时验证码屏加一条 NoticeBar，老用户仍可验证码登录）。

### 修复

- **「找回密码」返回时连续弹出两道「离开当前页面？」**（已登录状态下必现）：`/login` 是 `guestOnly` 路由，已登录访问会被路由守卫**重定向到首页**；vue-router 会为重定向后的新目标**再跑一次**本页的 `beforeRouteLeave`，于是同一导航链路上弹了两次确认框。已在中转处 `useUnsavedGuard` 增加「本次离开已确认」状态：确认后整条重定向链路直接放行，一次导航结束即复位（导航被中止留在本页时，下次离开仍会提示）。该组合式被 17 个表单/编辑页共用，同类问题（如已登录时从注册页点「直接登录」、会话失效被重定向到登录页）一并修复；新增 `useUnsavedGuard.spec.ts` 锁定「一条导航链路只询问一次」。
- **二次确认框被业务弹层遮盖导致按钮点不到**：TDesign Mobile 的 `DialogPlugin` 默认层级只有 2500，而 `Popup` 是 11500、`Toast` 是 12001，所以在「先打开底部弹层、再弹出确认框」的场景下（典型场景：安全中心里「绑定/更换手机号」「更换邮箱」填写了内容后返回，弹出的「放弃当前填写？」确认框会被底部弹层整个盖住，无法点击「放弃填写」），确认框会沉到业务弹层下面。现统一改用 [src/utils/confirmDialog.ts](https://github.com/GaoshuoZhang/Joinyuu-client-mobile/blob/main/src/utils/confirmDialog.ts) 的 `confirmDialog()`，显式把确认框层级抬到 11800（高于 Popup 11500，低于 Toast 12001/Message 15000），并把全站 35 处 `DialogPlugin.confirm` 调用点一并迁移，避免同类问题复发。
- **反向代理（域名）访问时登录日志与审计记成 `172.18.0.1` 而非访客真实 IP**：[server.mjs](https://github.com/GaoshuoZhang/Joinyuu-client-mobile/blob/main/server.mjs) 转发 `/api` 时会把「直接连接的对端地址」追加到 `X-Forwarded-For` 末尾，而容器端口经宿主机发布后该对端地址是 docker 网关，后端 `TRUST_PROXY=1` 取的又正是最后一跳。现改为**上游 `X-Real-IP` 优先、`X-Forwarded-For` 改写成单值**、不再追加对端地址：域名访问时记 Nginx 声明的 `$remote_addr`，IP 直连时记真实对端，且客户端伪造的 `X-Forwarded-For` 前缀会被丢弃。
- **下拉刷新时底部控件被容器边界裁掉、点不到（首页「登录后发布需求」按钮最明显）**：TDesign `PullDownRefresh` 根元素默认 `height: 100%` + `overflow: hidden`，而下拉只对内部 track 做 `translateY`（transform 不影响布局，容器高度不跟着长），内容下移后底部超出的部分被裁掉——按钮恰好是页面最后一个元素，就被「无形的框」盖住了，页面越短（如刚部署、首页无内容）越明显。已按「我的」「我的消息」已有的同口径写法，给**首页 / 社区 / 广场 / 需求**四个页面级下拉刷新补上 `height: auto; min-height: 100%; overflow: visible` 与 `__track { height: auto }`。经线上实测：未登录、空内容首页在各下拉深度下按钮全高可点，刷新提示仍正常显示在内容上方。

## [1.5.0] - 2026-10-17

首个正式发布版本（后端 / 管理后台 / 移动端同为 v1.5.0）。纯移动端应用，5 Tab 结构，全部页面接入真实接口（`/api/app/**`）。

### 新增

- **框架与账号**：5 Tab（首页 / 需求 / 社区 / 广场 / 我的）、手机号或邮箱或用户名登录（连续失败 3 次后需图形验证码）、注册、找回密码、换绑手机号/邮箱、修改密码、账号注销、用户协议与隐私政策。
- **业务闭环**：需求（浏览/筛选/详情/发布/响应/收藏/我的需求）、项目协作查看（里程碑与进度）、活动（报名、候补、签到、电子票与签到二维码）、积分商城（商品兑换、券码、订单）、公共空间预约（时段与费用）、资讯与投稿（图文编辑）、评论与点赞、企业/人才库/合作企业浏览、名片、申请提交与进度。
- **个人与成长**：多身份切换、等级权益（等级卡片轮播、积分消费折扣）、积分与经验流水、站内信与通知、全局搜索、实名认证或身份信息登记（按后端配置派生）。
- **客户主题包**：按部署启用客户主题（品牌 Logo/文案、明暗配色、组件与服务配色、1–10 级等级配色），主题切换冻结过渡避免拖影。
- **交互与体验**：下拉刷新（页面级统一）、选项卡滑动与吸顶、列表页内分页与筛选回第一页、定位签到（安全上下文校验 + 精度降级重试）、表单可访问性（字段 label 关联、Switch `aria-label`、行级操作互斥）、未保存变更离开保护。
- **版本号展示**：「我的 → 关于」新增「软件版本 v1.5.0」「服务端版本」（随 `/api/app/config` 下发）。

### 变更

- **术语口径**：「需求」指立项前的需求（发布/响应/收藏），「项目」仅指立项后的协作项目。
- **视觉与排版**：TDesign Mobile 组件统一 + 排版 Token First 体系；内容图统一 1px 内缩描边、嵌套圆角共心、按压反馈 0.96 缩放 150ms。

- 状态标签（`StateTag`）浅色变体对比度不足、未登记状态值兜底文案缺失。
- 表单提交后重试导致页面空白（改为接口成功后回填表单数据）。
- iOS 键盘弹出遮挡吸底提交栏（监听 `visualViewport.resize` 动态调整底部间距）。
- 主题切换时的颜色过渡拖影、TDesign 内置可点击元素（CheckTag / Navbar 返回 / Popup 关闭）的键盘通路缺失。
- 活动签到按钮文案与签到码校验（未开启位置校验显示「签到」，开启位置校验或位置+签到码显示「获取定位并签到」，开启签到码时需 6 位有效码）。
