# 聚屿社区 · Joinyuu Community

**面向共享办公空间、创业社区、产业园区与 OPC 社区的成员服务和运营管理系统。**

聚屿社区连接社区中的成员、企业、空间与服务，把人才展示、需求合作、活动参与、空间预约、企业代办和日常运营整合到同一套产品中。运营人员通过管理后台开展业务，成员通过移动 Web 或微信小程序使用社区服务。

> 本仓库用于公开介绍项目与说明产品功能。后端 API 与客户端源码由私有仓库维护，不随本仓库公开。

## 项目简介

社区运营既需要管理成员、企业和场地，也需要持续促成交流、合作与服务交付。聚屿社区围绕这些日常工作，提供三个相互配合的使用端：

| 使用端 | 面向人群 | 主要用途 |
| --- | --- | --- |
| 管理后台 | 社区运营、业务办理、财务与管理人员 | 维护社区资源，处理审核、预约、订单、服务申请与日常运营 |
| 移动 Web | 社区成员、企业负责人及访客 | 通过手机浏览器了解社区、展示名片、寻找合作、参与活动和办理服务 |
| 微信小程序 | 微信环境下的社区用户 | 在微信内使用社区主要业务，接收并查看个人办理和参与记录 |

产品适用于以下场景：

- **共享办公与联合办公**：管理工位、办公室、租约与公共空间预约，连接入驻成员。
- **创业社区与产业园区**：展示企业与人才，承接入驻申请、企业服务和社区活动。
- **OPC 与专业人才社区**：通过个人名片、技能展示、需求响应和项目协作连接独立创业者与企业。
- **综合社区服务运营**：将内容传播、成员成长、积分激励和服务办理统一管理。

## 项目优势

### 成员、企业与业务关系相互关联

同一账号可以关联个人与企业身份。成员展示个人能力，企业维护组织信息，需求、活动、项目和服务记录围绕实际参与主体展开，方便社区了解“谁在参与、代表谁参与、参与了什么”。

### 后台办理与成员操作相互衔接

成员提交申请、报名或材料后，工作人员在后台受理、审核和反馈；成员可以查看处理状态、补充资料与最终结果。双方围绕同一条业务记录持续沟通。

### 合作与服务覆盖社区日常场景

人才库、企业库和需求合作帮助成员发现资源；活动、空间与企业代办承接具体服务；项目、订单和办理记录保留后续进展，让信息展示能够接上实际行动。

### 运营规则与品牌展示可配置

社区可以按自身业务设置功能入口、申请表单、积分经验规则、等级权益、名片字段与展示方式，也可以调整站点品牌、移动端主题和首页内容编排。

### 按角色分工，保留处理记录

后台通过账号、角色、操作权限和数据范围支持团队分工，结合审核记录、操作审计与举报处置，便于追踪业务处理过程。

### 兼顾公开展示与个人隐私

个人与企业名片支持展示范围控制，成员可编辑字段与公开展示字段分别管理。服务材料、个人记录及联系方式根据业务规则和访问权限提供。

## 后台端功能说明

后台面向社区运营团队，按业务领域组织工作。不同工作人员看到的菜单、数据与可执行操作由其角色和权限决定。

### 1. 成员与企业管理

| 功能 | 说明 |
| --- | --- |
| 用户管理 | 查看成员资料、账号状态、关联身份及相关业务信息，处理成员日常管理事项 |
| 社区个体 | 管理社区人才身份，维护个人名片与字段规则 |
| 社区企业 | 维护入驻企业资料、负责人、成员关系及企业名片 |
| 合作企业 | 管理社区外部合作企业，展示合作资源 |
| 申请审核 | 处理人才登记、企业入驻及企业合作等申请，反馈审核结果 |
| 名片展示管理 | 分别设置允许成员编辑的字段与对外展示的字段，控制人才库、企业库的信息呈现 |

### 2. 需求与项目管理

- **需求管理**：查看与维护社区需求，处理发布审核，跟踪需求状态。
- **响应审核**：查看合作响应及参与主体，处理相关审核事项。
- **项目管理**：查看立项后的参与关系、协作进度、里程碑与结项记录。

运营人员可以从成员发布的合作意向继续跟进实际协作过程。

### 3. 活动与内容运营

| 功能 | 说明 |
| --- | --- |
| 活动管理 | 维护活动信息、报名安排和参与规则，查看活动详情与报名情况 |
| 报名与电子票 | 管理报名记录、候补、电子票与签到核销情况 |
| 活动反馈 | 查看参与成员的评分与反馈，了解活动体验 |
| 文章资讯 | 管理栏目、发布内容、审核成员投稿并查看相关统计 |
| 首页公告与轮播 | 维护社区公告和首页展示内容 |
| 社区政策 | 发布社区服务与政策信息，向成员展示介绍及相关附件 |

### 4. 空间与租赁管理

- **办公资源**：维护办公位、办公室等空间资源。
- **租赁管理**：维护租约、租赁状态及关联账单，查看租约详情。
- **公共空间**：配置可预约空间、开放时段与相关规则。
- **预约管理**：查看预约记录并处理相关业务事项。

### 5. 企业代办服务

| 服务 | 主要办理内容 |
| --- | --- |
| 企业注册 | 接收企业、股东、主要人员与证件材料，跟踪注册代办进度 |
| 财税服务 | 按所选财税事项收集需求与材料，记录办理过程 |
| 工商变更 | 按变更事项接收资料，跟进补件及处理结果 |
| 资质许可 | 按许可或备案类型接收材料，管理办理进度 |

工作人员可受理申请、要求补充材料、记录内部备注，以及完成或驳回申请。成员在客户端查看对应状态并补充资料。服务提交用于表达办理需求，具体承接范围和办理结果由工作人员确认。

### 6. 积分、成长与商城

- **积分规则**：配置积分获取与使用规则，查询积分发放记录。
- **经验与等级**：配置经验规则、等级和权益，查询经验值发放记录。
- **商品管理**：维护商品、库存、兑换条件与有效期等信息。
- **订单管理**：处理兑换订单、查看券码与核销记录。
- **参与规则**：按身份与等级维护相关业务参与限制。

### 7. 交易经营与售后

| 功能 | 说明 |
| --- | --- |
| 经营概览 | 查看交易相关汇总与经营数据 |
| 应收与交易 | 查询商品、空间、活动及租约账单关联的应收和交易记录 |
| 收款处理 | 查看线上支付结果，登记与复核线下收款 |
| 退款处理 | 查看成员退款申请，进行审批、结果查询和异常跟进 |

线上支付方式与可用范围根据实际开通的渠道提供，订单、付款、退款及服务交付分别记录状态。

### 8. 沟通、设置与治理

- **用户留言**：查看成员咨询，回复问题并保留沟通记录。
- **消息管理**：维护消息渠道与模板，为审核、报名、预约和订单等业务提供通知。
- **品牌与首页**：维护站点信息、主题、快捷入口及首页信息流，分别编排游客与登录成员的首页内容。
- **业务设置**：维护业务开关、表单、展示字段、规则与协议等配置。
- **账号与权限**：管理工作人员账号、角色、操作权限与数据范围。
- **运行与审计**：查看运行信息、登录记录与操作审计。
- **治理与资源**：处理举报和注销工单，管理素材、归档与回收站等资源。

## 客户端功能说明

客户端围绕“发现社区资源 → 参与业务 → 查看进展”组织体验。移动 Web 与微信小程序承接相同的核心社区业务，具体入口按社区开放范围、成员身份与权限显示。

### 1. 五个主要入口

| 入口 | 可以做什么 |
| --- | --- |
| 首页 | 查看社区公告、推荐内容与常用服务，快速进入人才、企业、活动及业务办理 |
| 需求 | 浏览和搜索合作需求，查看详情，发布需求或提交响应 |
| 社区 | 查看社区服务、人才库与企业库，了解成员能力及企业资源 |
| 广场 | 浏览活动与资讯，参与报名、阅读和讨论 |
| 我的 | 管理资料、身份、名片与企业，查看申请、项目、订单、预约、消息及账号设置 |

全局搜索帮助成员查找需求、活动、文章、人才、企业、社区服务和空间。

### 2. 个人资料与人才展示

成员可以维护头像、昵称、个人简介等资料，申请社区个体身份，并完善个人名片。名片可展示技能、教育经历、工作经历、项目经历、荣誉证书与相关链接；实际可编辑和展示的内容由社区规则决定。

通过人才库，成员可以按关键词发现社区人才、查看公开名片，并收藏感兴趣的资源。个人名片支持公开范围和部分信息可见性设置。

### 3. 企业与团队

企业负责人或获授权成员可以查看关联企业，维护允许编辑的企业资料与名片，按权限邀请和管理成员、处理邀请及负责人交接。

有入驻或合作意向的成员可以提交相应申请，并在个人办理记录中查看审核状态。

### 4. 需求合作与项目协作

1. 浏览或搜索需求，了解合作内容和发布方信息。
2. 按可用身份发布需求，或对已有需求提交响应。
3. 查看需求、响应的处理状态与结果。
4. 对已立项的协作，在“我的项目”中查看进展，按参与权限提交或处理里程碑事项。

需求用于表达合作意向，项目用于记录立项后的协作过程。

### 5. 活动、电子票与内容互动

- 查看活动时间、地点、介绍和报名要求。
- 提交报名，查看报名结果、候补状态与电子票。
- 在开放条件内完成签到，并在活动结束后提交反馈。
- 阅读社区资讯与政策信息，按开放规则点赞、收藏、评论或提交文章投稿。
- 在个人记录中查看已参与活动与投稿处理情况。

### 6. 空间预约、租约与账单

成员可以查看空间信息与可预约时段，选择起止时间后提交预约。涉及费用的业务按页面显示完成积分兑换或现金支付，并在个人中心查询预约详情、租约与关联账单。

### 7. 企业服务办理

在企业代办入口选择所需服务，填写对应事项、联系人与材料后提交申请。企业注册采用分步填写，涵盖企业信息、股东、主要人员以及材料确认。

申请提交后，可以查看办理记录、处理进度与反馈；需要补件时，按提示补充材料或修改重提，继续跟进同一条申请。

### 8. 积分、等级与交易记录

| 功能 | 说明 |
| --- | --- |
| 签到与积分 | 参与签到及社区业务，查看可用积分与相关记录 |
| 我的等级 | 查看适用身份的经验、当前等级与对应权益 |
| 积分商城 | 浏览商品、完成兑换，并查看兑换订单及可用券码 |
| 现金交易 | 查看待付款及其他交易订单，完成付款并查询支付结果 |
| 退款与售后 | 对符合条件的订单提交退款申请，查看审批和资金处理进度 |

### 9. 消息、记录与账号安全

“我的”集中提供站内信、社区留言、收藏、阅读历史及个人业务记录入口。成员可查看审核反馈、企业邀请、办理进展及其他业务通知，也可以向社区留言并查看工作人员回复。

账号设置提供资料维护、账号与安全、身份信息登记、通知偏好及隐私相关功能，按账号状态开放相应操作。

## 典型业务流程

| 场景 | 成员侧 | 运营侧 |
| --- | --- | --- |
| 人才加入社区 | 提交人才登记 → 完善个人名片 → 展示能力与经历 | 审核申请 → 维护身份与名片规则 → 展示社区人才 |
| 促成合作 | 发布或响应需求 → 查看处理结果 → 参与项目协作 | 审核需求与响应 → 跟进立项和项目进度 |
| 组织活动 | 查看活动 → 报名与获取电子票 → 签到 → 提交反馈 | 发布活动 → 管理报名与候补 → 查看签到和反馈 |
| 使用公共空间 | 选择空间与时段 → 提交预约 → 完成适用结算 → 查看预约记录 | 配置空间与规则 → 管理预约 → 跟进交易与使用情况 |
| 办理企业事务 | 选择服务 → 填写并提交材料 → 补件 → 查看结果 | 受理申请 → 核实需求与材料 → 反馈或办结 |
