# 后台全部业务页面登录态端到端测试报告

测试日期：2026 年 10 月 15 日（Asia/Shanghai）。范围：`apps/admin`，承接 UI 整改后的版本；保持 TDesign 组件体系，未检查或调整配色。

登录态页面清单中的 54 个路由、78 个页面内选项卡、52 个主接口失败恢复用例全部通过。另有 13 项业务链路、11 项交互及布局检查、4 项权限和会话检查通过。六组最终 checkpoint 共 212 条记录，失败 0；未捕获页面 JavaScript 异常或非 API 资源加载错误。本轮发现 3 处产品缺陷，均已修复并复测。

## 本轮发现与修复

| 缺陷 | 修复 | 复测证据 |
| --- | --- | --- |
| 办公位弹窗等待区域接口后才回填，慢加载可能覆盖用户已经输入的内容 | 先同步重置、回填、设置基线并清校验，再加载区域选项；新增默认区域仅在弹窗仍可见且未修改时补入 | 编辑、新增两种模式延迟真实请求，接口返回后输入均保留 |

复测前必须准备隔离数据库、Redis DB 14、可登录测试账号、有效许可证、附件及所需状态记录，并重新启动 17757 API 和 17758 production Admin。脚本会写入并消耗部分夹具，例如待核销订单和待审核记录；完整业务组重新执行前应恢复测试前快照或准备相应状态。此脚本不负责建立数据库或重置夹具，仅限制访问本地 Admin 17758，使用时仍须确认代理连接隔离 API。

在仓库根目录运行所需组：

```powershell
node apps/admin/test/authenticatedE2e.mjs routes
node apps/admin/test/authenticatedE2e.mjs tabs
node apps/admin/test/authenticatedE2e.mjs recovery
node apps/admin/test/authenticatedE2e.mjs business
node apps/admin/test/authenticatedE2e.mjs interaction
node apps/admin/test/authenticatedE2e.mjs security
```

`PLAYWRIGHT_PACKAGE` 可指向能够解析 Playwright 的已安装运行时 `package.json`，覆盖脚本中的本机 Codex 缓存路径；`ADMIN_E2E_PASSWORD` 可通过环境变量提供隔离管理员密码。`ADMIN_E2E_MATCH` 支持按用例名正则筛选，并覆盖同名 checkpoint，不代表整组已重新执行。最终快照和报告保存本次执行结果，不随后续复跑自动更新。
